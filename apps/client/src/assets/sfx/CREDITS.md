# Sons enregistrés

Chaque fichier est un montage (couches, réverbe, mastering) de sons tirés de bibliothèques libres.

| Fichier | Moment | Sources |
| --- | --- | --- |
| `aov-tourbillon.mp3` | Action ou vérité : la bouteille tourne | « swish » du pack *Battle sound effects* d’Ogrebane (OpenGameArt, CC0) ; tinkle bell FluidR3 GM |
| `aov-trinque.mp3` | Action ou vérité : la bouteille s'arrête | verres du pack *100 CC0 SFX* de rubberduck (OpenGameArt, CC0) ; tinkle bell FluidR3 GM |
| `aov-fanfare.mp3` | Action ou vérité : défi validé | trompette, cuivres, cor, timbales, glockenspiel FluidR3 GM |
| `quiz-harpe.mp3` | Quiz : la question arrive | harpe FluidR3 GM |
| `quiz-cartes.mp3` | Quiz : les réponses s'ouvrent | *Casino Audio* de Kenney (CC0) |
| `quiz-bois.mp3` | Quiz : réponse verrouillée | woodblock FluidR3 GM ; bois du pack *100 CC0 SFX* de rubberduck (CC0) |
| `quiz-coeur.mp3` | Quiz : 5 dernières secondes | taiko FluidR3 GM |
| `quiz-bravo.mp3` | Quiz : bonne réponse | trompette, cuivres, glockenspiel FluidR3 GM |
| `quiz-rate.mp3` | Quiz : mauvaise réponse | pizzicato, contrebasse FluidR3 GM |
| `quiz-podium.mp3` | Quiz : podium | timbales, cymbale inversée, trompette, cuivres, cor, tutti FluidR3 GM |
